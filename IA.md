# Registro de Utilização de Inteligência Artificial

## 1. Identificação do projeto

**Nome:** CineFinder — Buscador de Filmes e Séries

**Disciplina:** Programação Web II

**Tecnologias:** HTML5, CSS3, JavaScript e API.
x'x
## 2. Objetivo

Desenvolver uma aplicação web simples para pesquisar filmes e séries, consultar informações sobre os títulos e visualizar seus cartazes.

O projeto será desenvolvido em etapas, priorizando a compreensão dos conceitos fundamentais de desenvolvimento web.

## 3. Prompt utilizado

Atue como um desenvolvedor web e professor de Programação Web II.

Ajude-me a desenvolver um projeto acadêmico chamado CineFinder, um buscador de filmes e séries.

O projeto deve utilizar exclusivamente HTML5, CSS3, JavaScript puro e uma API para consultar informações sobre filmes e séries. Não utilize frameworks ou bibliotecas externas de interface.

Organize o projeto em arquivos e pastas, separando HTML, CSS, JavaScript, imagens e documentação.

A aplicação deverá possuir três telas principais:

1. Página inicial com cabeçalho, campo de pesquisa e sugestões de filmes e séries.
2. Página de resultados com cartões contendo cartazes, títulos, anos e tipos de conteúdo.
3. Página de detalhes com cartaz, título, gênero, ano, sinopse e outras informações disponíveis.

Utilize a OMDb API para a futura integração com os dados dos filmes e séries.

Desenvolva o projeto gradualmente, com código simples, organizado, comentado quando necessário e adequado para estudantes que estão aprendendo desenvolvimento web.

### Requisitos da Etapa 1

- Criar a estrutura HTML5 de todas as telas.
- Desenvolver a estilização utilizando CSS3.
- Não implementar JavaScript nesta etapa.
- Utilizar Flexbox ou CSS Grid para organizar os elementos.
- Implementar pelo menos uma Media Query para adaptar o layout a diferentes tamanhos de tela.
- Garantir que a interface seja responsiva para computadores, tablets e celulares.
- Manter os arquivos organizados em pastas.
- Utilizar dados e imagens ilustrativas estáticas enquanto a API não estiver integrada.
- Evitar dependências desnecessárias e manter o projeto fácil de compreender.

Explique as principais partes do código de maneira objetiva, permitindo que o estudante compreenda a estrutura e consiga realizar alterações por conta própria.

Não avance para a implementação JavaScript antes da conclusão da primeira etapa.

## 4. Forma de utilização

A inteligência artificial foi utilizada como ferramenta de apoio para planejar a arquitetura, organizar os arquivos e orientar o desenvolvimento das interfaces.

O código deverá ser revisado, testado e compreendido pelo estudante antes de sua entrega.

## 5. Etapas previstas

- **Etapa 1:** Estrutura HTML5 e estilização CSS3 das três telas, com layout responsivo.
- **Etapa 2:** Implementação da pesquisa e integração com a API utilizando JavaScript.
- **Etapa 3:** Exibição dinâmica dos resultados e detalhes dos títulos.
- **Etapa 4:** Testes, correções, documentação e publicação do projeto.
