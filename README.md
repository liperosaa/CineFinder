O **CineFinder** é um site desenvolvido para facilitar a busca por filmes e séries, ajudando pessoas que desejam encontrar opções de entretenimento de forma simples e organizada. O público-alvo são pessoas que gostam de assistir a filmes e séries e querem consultar informações sobre diferentes títulos. O projeto utilizará a **API OMDb (Open Movie Database)** para obter informações como títulos, pôsteres, ano de lançamento, gênero e sinopse. Suas três principais funcionalidades serão: **1)** pesquisar filmes e séries pelo nome; **2)** visualizar os resultados da pesquisa em cards com informações básicas; e **3)** acessar uma página de detalhes para consultar informações mais completas sobre o título selecionado. O site será desenvolvido com HTML5, CSS3 e JavaScript, com layout responsivo para computadores e celulares.
